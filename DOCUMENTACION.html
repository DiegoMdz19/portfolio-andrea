1. ¿Qué es este proyecto?

Este es el portfolio profesional de Andrea López, fotógrafa y piloto de dron. Es una página web que muestra su trabajo (fotos, vídeos), sus servicios y permite que los clientes contacten con ella.

Lo importante es que no necesita WordPress ni ningún sistema de gestión externo. Tiene su propio panel de administración integrado que permite cambiar casi todo el contenido sin tocar código.

✅ ¿Qué puede hacer Andrea desde el panel?
Subir fotos · Subir vídeos · Editar textos · Cambiar servicios y precios · Gestionar testimonios · Ocultar/mostrar secciones · Cambiar contraseña
🌐 URL de la web: https://andrealopezfoto.es
🔑 Cómo abrir el panel admin: En cualquier página, escribe andrea en el teclado (sin hacer clic en ningún campo) o toca el logo 3 veces rápido en móvil.

Estos son los ficheros que componen la web y para qué sirve cada uno:

fotos/Carpeta con imágenes locales (como el retrato de la sección "Sobre mí").
videos/Carpeta con vídeos locales (como el vídeo del hero).
sonidos/Carpeta con sonidos de ambiente de la web.

3. Panel de administración

El panel admin es la herramienta para gestionar el contenido de la web sin tocar código. Los cambios se guardan en Firebase y se ven en todos los navegadores y dispositivos.

🔓 Cómo acceder

En ordenador: Escribe la palabra andrea con el teclado (sin clic en ningún campo de texto).
En móvil: Toca el logo "Andrea López" del menú 3 veces seguidas y rápido.

Aparece un campo de contraseña. La contraseña por defecto es la configurada en el sistema.

📊 Pestaña: Estadísticas

Muestra un resumen rápido: número de fotos, vídeos y visitas. También hay botones para exportar e importar la configuración completa (útil como copia de seguridad).

📂 Pestaña: Secciones

Permite activar o desactivar cada sección de la web. Por ejemplo, si no quieres mostrar los testimonios temporalmente, apágalos aquí — desaparecen del menú y de la página sin borrarlos.

⚠️ Las secciones Hero y Contacto no se pueden desactivar porque son imprescindibles.

Dentro de cada sección también puedes:

  • Hero: cambiar el vídeo o imagen de fondo
  • Sobre mí: editar los párrafos de texto y gestionar el carrusel de fotos
  • Galería: subir y eliminar fotos de la galería
  • Vídeos: añadir y eliminar vídeos
  • Servicios: editar servicios, precios, iconos y ocultarlos individualmente
  • Proceso: editar los 4 pasos del proceso de trabajo
  • Testimonios: añadir, editar y eliminar testimonios de clientes

4. Firebase — la base de datos

Firebase es el servicio de Google que almacena todos los datos dinámicos de la web: fotos, vídeos, configuración del panel. Es gratuito para el volumen que usa este portfolio.

Colección en FirebaseQué guarda
photosLas fotos de la galería (URL de Cloudinary + título + categoría)
videosLos vídeos (ruta + título + descripción + categoría)
sobre_photosLas fotos del carrusel de "Sobre mí"
config/siteToda la configuración del panel (textos, servicios, testimonios, secciones visibles, contacto…)
📍 Proyecto Firebase: andrea-portfolio-a0817
🔗 Consola: console.firebase.google.com/project/andrea-portfolio-a0817

🔒 Reglas de seguridad

Las reglas (firestore.rules) controlan quién puede escribir en la base de datos. La configuración actual es:

  • Leer: cualquier persona puede leer (necesario para que los visitantes vean las fotos)
  • Escribir: solo el administrador autenticado (es decir, solo desde el panel admin con contraseña correcta)

¿Cuándo desplegar las reglas?

Si en el futuro añades una funcionalidad nueva que requiera una colección nueva en Firestore, deberás actualizar el fichero firestore.rules y ejecutar:

firebase deploy --only firestore:rules

Para la web tal como está ahora, no necesitas hacer nada más.

📦 Cloudinary — almacenamiento de imágenes

Las fotos no se guardan en Firebase. Se suben a Cloudinary, un servicio especializado en imágenes que las comprime y optimiza automáticamente. Firebase solo guarda la URL de cada foto.

Cuenta Cloudinary: cloud dnof8srry · preset andrea_portfolio

5. Vercel — dónde vive la web

Vercel es el servicio que aloja la web y la hace accesible en internet. Cada vez que subes cambios al repositorio de Git, Vercel los despliega automáticamente.

¿Cómo desplegar cambios?

1
Guarda los cambios en los ficheros
2
Abre Warp (o cualquier terminal) en la carpeta del proyecto
3
Ejecuta: git add . && git commit -m "descripción del cambio" && git push
4
Vercel detecta el push y despliega automáticamente en ~30 segundos
✅ La URL https://andrealopezfoto.es se actualiza sola. No hay que hacer nada más.

7. Service Worker — modo offline y velocidad

El Service Worker (sw.js) es un programa invisible que el navegador instala en el dispositivo del visitante. Sirve para dos cosas:

  • Velocidad: en visitas posteriores, el HTML, CSS y JS se cargan desde la memoria del navegador sin esperar a descargarlos de nuevo. La web abre instantáneamente.
  • Offline: si el visitante no tiene conexión, la web sigue abriendo (sin las fotos de Firebase, pero el resto funciona).

¿Cuándo cambiar la versión?

Cuando hagas cambios importantes en el diseño o el código y quieras que todos los visitantes vean la versión nueva, abre sw.js y cambia el número de versión:

AntesDespués
const CACHE_NAME = 'andrea-v1';const CACHE_NAME = 'andrea-v2';

Así el Service Worker borra la caché vieja y descarga la nueva versión para todos los visitantes.

8. Seguridad

🔒 Cabeceras HTTP (vercel.json)

El servidor envía cabeceras de seguridad con cada respuesta para proteger a los visitantes:

CabeceraPara qué sirve
X-Frame-OptionsEvita que la web se incruste en iframes de otras páginas (protege contra clickjacking)
X-Content-Type-OptionsEvita que el navegador interprete mal el tipo de fichero
Referrer-PolicyControla qué información de origen se comparte al navegar
Permissions-PolicyDesactiva acceso a cámara, micrófono y geolocalización

🔑 Contraseña del panel admin

La contraseña se guarda como un hash SHA-256 en el navegador. Nunca se guarda en texto plano. Nadie que acceda al código fuente puede leer la contraseña real.

📋 Reglas de Firestore

La base de datos está protegida: los visitantes pueden leer datos pero no escribir. Solo el administrador, después de autenticarse con la contraseña correcta, puede modificar el contenido.

🍯 Honeypot anti-spam

El formulario de contacto tiene un campo oculto que los humanos no ven pero los bots sí rellenan. Si ese campo llega con contenido, el mensaje se descarta silenciosamente sin enviarse.

11. Carpetas, álbumes privados y códigos QR

El sistema de carpetas permite organizar las fotos y compartirlas con clientes de forma privada mediante un enlace o código QR.

📁 Crear y gestionar carpetas

Ve a Panel admin → Herramientas → Carpetas.

  • Escribe el nombre de la carpeta y pulsa Crear ✓
  • Cada carpeta tiene dos opciones:
    • Pública: la carpeta aparece como filtro en la galería del portfolio público
    • Descarga: los clientes que accedan por QR pueden descargar las fotos como ZIP
  • Para renombrar una carpeta: edita el campo de texto y haz clic fuera
  • Para eliminar: botón ✕ (las fotos no se borran, solo se desasignan)

📸 Asignar fotos a carpetas

Al subir fotos nuevas: Secciones → Galería → arrastra la foto → en el formulario selecciona la carpeta antes de pulsar Añadir ✓.

Fotos ya subidas: Secciones → Galería → en cada foto hay un desplegable para cambiar la carpeta. El cambio se guarda automáticamente.

⚠️ El checkbox Permanente que aparece en cada foto del admin evita que esa foto se elimine con el auto-borrado automático.

📱 Generar y compartir el código QR

1
Panel admin → Herramientas → Carpetas
2
Pulsa el botón QR en la carpeta que quieras compartir
3
Escanea el código QR con el móvil o copia el enlace
4
El cliente ve solo las fotos de esa carpeta. Si tiene Descarga activada, puede descargar un ZIP con todas las fotos
URL del álbum: https://andrealopezfoto.es?album=TOKEN
El token es único por carpeta. Para cambiar el acceso, elimina la carpeta y crea una nueva.

Descarga ZIP para el cliente

Si la opción Descarga está activada en la carpeta, el cliente verá un botón “Descargar ZIP”. Al pulsarlo, el navegador descarga todas las fotos de la carpeta en un único fichero ZIP. La barra de progreso indica el avance.

⚠️ Las fotos pesadas pueden tardar varios segundos en comprimirse. Es normal.

El sistema puede eliminar automáticamente fotos antiguas para mantener limpia la base de datos.

Dónde configurarloPanel admin → Configuración → Avanzado
Valor por defecto365 días
0 = desactivadoLas fotos nunca se eliminan automáticamente

⚠️ Las fotos marcadas como Permanente (checkbox en la galería admin) nunca se eliminan aunque superen el límite de días.
🔴 Cloudinary no borra las imágenes automáticamente cuando se eliminan de Firestore. Solo desaparecen de la web, pero siguen ocupando espacio en Cloudinary. Limpia Cloudinary manualmente de vez en cuando desde cloudinary.com.

Los vídeos se suben exactamente igual que las fotos: arrastra el fichero MP4 a la zona de subida.

1

10. Solución de problemas

❌ No puedo entrar al panel admin

Causa: Contraseña incorrecta o estás haciendo clic en un campo de texto antes de escribir "andrea".
Solución: Haz clic en una zona vacía de la página primero, luego escribe andrea. Si olvidaste la contraseña, en andrea.js busca ADMIN_HASH y contacta con el desarrollador.

❌ Los cambios del panel no se ven en otro navegador

Causa: Firebase puede tardar unos segundos en sincronizar.
Solución: Recarga la página en el otro navegador. Si sigue sin verse, comprueba la conexión a internet.

❌ Las fotos no se suben

Causa: Problema con Cloudinary o la conexión.
Solución: Comprueba que el preset andrea_portfolio existe en tu cuenta de Cloudinary (cloudinary.com) y que es de tipo "Unsigned".

❌ El formulario de contacto no llega

Causa: EmailJS no está configurado o la plantilla ha cambiado.
Solución: Accede a emailjs.com, verifica que el servicio service_obw8dnq y la plantilla template_ucs9imo existen y están activos.

❌ La web no se actualiza tras subir cambios

Causa: El Service Worker está sirviendo la versión antigua desde caché.
Solución: Cambia la versión en sw.js de andrea-v1 a andrea-v2 y vuelve a hacer push.

❌ Error "permission denied" al escribir en Firebase

Causa: Las reglas de Firestore están activas y el inicio de sesión anónimo no está habilitado.
Solución: En Firebase Console → Authentication → Sign-in method → Anónimo → Activar.
